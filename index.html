SUPPORT

Frequently asked questions

Why is no code appearing?
The bot must be running on the server. If you see "already paired", that number already has a session — unpair it first.
What if the code expires?
Codes last 5 minutes. Click Pair again to generate a fresh one.
What does "already paired" mean?
That WhatsApp number is already linked to the bot. Delete or unpair the existing session before pairing again.
Can one number pair twice?
No — one WhatsApp number links to the bot once at a time.
Is my number safe?
Your session is encrypted and stored in the database. Only you can pair your number.
